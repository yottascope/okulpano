# Okul Pano

**Pardus ETAP** ve **Windows** akıllı tahtalar için geliştirilmiş, %100 çevrimdışı çalışabilen dijital okul panosu ve otomatik zil sayacı uygulaması.

## Özellikler
- **%100 Çevrimdışı Çalışır.**
- **Ders, teneffüs ve öğrenci zili geri sayımı + JSON üzerinden özelleştirilebilir zil saatleri.**
- **Yüksek kapasiteli afiş ve fotoğraf gösterimi için galeri.** 
- **Duyurular.**
- **Şifre Korumalı Kontroller:** Yönetim paneli, tam ekran/küçültme ve çıkış tuşları öğretmen şifresi ile korunur.

## Kurulum ve Derleme

```bash
npm install
npm run setup
npm start
```
